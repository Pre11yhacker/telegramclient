## ✦ ✦ ✦ ИНТЕРФЕЙС HTML-ОТЧЁТОВ ✦ ✦ ✦

### Досье включает
- ✓ Имя, ID, номер телефона
- ✓ Все юзернеймы (обычные + NFT)
- ✓ Bio с извлечением ссылок
- ✓ Бейджи (верифицирован, премиум, бот, скам...)
- ✓ Полный список общих чатов
- ✓ Историю подарков
- ✓ Количество историй и подписчиков
- ✓ Статус «в сети» / «был(а)»
- ✓ Наличие обоев

### Логи сообщений включают
- ✓ Тепловую карту активности (24 часа)
- ✓ Статистику по типам сообщений
- ✓ Временную шкалу сообщений
- ✓ Встроенные превью фото
- ✓ Флаги «ответ», «репост», «редактировано»
- ✓ Прямые ссылки на сообщения в Telegram
